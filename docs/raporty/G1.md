# Bramka G1 — odbiór prototypu Plant P0 (M1)

Model-Author: Codex · sesja 026 · 2026-10-20

**Stan:** automatyczny odbiór P0 zakończony PASS: [raport](prototypy/P0-2026-10-20.md). Poniższe próby ręczne pozostają do wykonania przez właściciela. Nie oznaczać M1 jako zakończonego, dopóki wymagania REQ-VD/VM/QA, scenariusze i testy nie przejdą, a raport P0 nie zostanie zapisany. Wszystko dotyczące fizycznej maszyny: **NIEZWERYFIKOWANE NA SPRZĘCIE**.

## 1. Automatyczna bramka w Debianie 12

W katalogu repozytorium, po zainstalowaniu zależności:

```bash
make lint test test-c test-san
python3 tools/check_requirements.py -v
make plant-matrix
python3 -m pytest tests/test_ip_guard.py -q
```

Jeżeli dostępny jest LinuxCNC 2.9 RIP, dodatkowo:

```bash
make test-linuxcnc
```

Wyniki zapisuj w `docs/raporty/prototypy/`. W raporcie odnotuj wersję systemu, SHA commita, PASS/FAIL, pominięcia i przyczynę każdego pominięcia. **Nie uznawaj samego pokrycia wymagania za dowód, że test przeszedł.** REQ-VD-06 należy do sesji 061 (M5), nie do G1.

## 2. Budowa i uruchomienie wirtualnej obrabiarki

- [ ] Uruchom Plant według [PLANT_START.md](../PLANT_START.md) na konfiguracji z `config/machines/`.
- [ ] Sprawdź, czy panel Plant pokazuje osie, napędy, czujniki, alarmy i stan łącza.
- [ ] Skopiuj szablon napędu do nowej instancji i sprawdź niezależność parametrów.
- [ ] Zmień parametry maszyny w edytorze, zapisz i przeładuj bez restartu; upewnij się, że walidacja odrzuca błędny `machine.yaml`.

## 3. Scenariusz first_motion

```bash
python3 tools/run_scenario.py first_motion --out docs/raporty/prototypy
```

- [ ] Raport wskazuje PASS dla wszystkich kryteriów.
- [ ] Z LinuxCNC + Plant wykonaj bazowanie i bezpieczny przejazd zgodnie z konfiguracją maszyny.
- [ ] Zmierz pozycję zadaną i rzeczywistą oraz błąd nadążania; zapisz wartości i jednostki.
- [ ] Przerwij łącze LRT-NET: sprawdź watchdog i bezpieczny stan napędów.
- [ ] Sprawdź krańcówkę, zderzak i strefę zakazaną; wynik musi zgadzać się z wyrocznią testową.

## 4. Masa, bezwładność i błąd nadążania

- [ ] W panelu Plant zapisz parametry początkowe i wykonaj ten sam ruch G1.
- [ ] Zwiększ masę / bezwładność osi w dozwolonym zakresie i powtórz identyczny ruch.
- [ ] Porównaj maksymalny błąd nadążania, opóźnienie i ewentualne alarmy z przebiegiem początkowym.
- [ ] Przywróć ustawienia początkowe; sprawdź, czy rezultat jest odtwarzalny.
- [ ] Sprawdź, że zmiana parametrów symulatora nie wyłącza fizycznego safety.
