Nowa diagnostyka zachowała próbkę przy odebraniu komunikatu około 0,4943 s
od startu drivera, **przed T0 programu**:

|---|---:|
| joint 3 homing / homed | 1 / 0 |
| joint 3 ferror_current / highmark | 0,43 / 0,43 mm |
| joint 3 output / input | 0,45 / 0 mm |
| joint 3 velocity | 20 mm/s |
| reply-age / connected | 1 / true |
| missed / plant-lost / plant-late | 3 / 0 / 0 |

To odczyty NML i kolejnych pinów HAL poza RT. Nie określają cyklu powstania
błędu ani przyczyny. Zwłaszcza 0,43 mm nie należy utożsamiać z wartością, która
wyzwoliła zabezpieczenie; kanał błędów i status nie są atomowym śladem.
Liczniki łącza są stanem w chwili odczytu, nie dowodem przyczynowości.

Istniejący runner ponowił bazowanie; następnie program uzyskał 5/5 PASS.
Maksima programu: X 0,11211 mm, Y 0,05676 mm, Z 0,04887 mm.
**PASS programu nie oznacza bezbłędnego pierwszego bazowania**, naprawy historycznych
0,3 mm ani zaliczenia serii 10 kolejnych przebiegów. To pojedynczy pomiar,
bez kontrolowanego benchmarku obciążenia i bez wniosku o optimum ramp.
