# Wzorce skórek dostarczone przez właściciela

Model-Author: Codex · 2026-10-23. Źródło: https://megawrzuta.pl/hdimgnec,
paczka `linumert-showcase.zip` z czterema WEBP i stroną prezentacyjną.
Obejrzano wszystkie cztery obrazy; to referencje wyglądu, nie gotowy HMI.
Pochodzenie i ograniczenia redystrybucji: `docs/PROVENANCE.md`.

- Classic Digital: prostokątne metalowe moduły, DRO nad programem po lewej,
  dominująca ścieżka pośrodku, maszyna po prawej, dolne fizyczne kontrolki.
- Industrial Pro: duża maszyna po lewej, DRO pośrodku, ścieżka nad programem
  po prawej; metalowe ramki, kontrolki cyklu i okrągłe wskaźniki.
- Cyberdeck: DRO / program / ścieżka w górnym rzędzie, maszyna na dole po lewej,
  moduły techniczne po prawej; ścięte narożniki i świetlne krawędzie.
- Organic Vector: DRO nad programem po lewej, maszyna i ścieżka u góry;
  obłe wyspy wskaźników i kontrolek, płynne metalowe obramowania.

Podgląd odwzorowuje obecnie hierarchię paneli i rodziny obudów. Kontrolki,
fotorealistyczne modele, pełne podstrony i integracja CNC pozostają dalszą pracą.
Nie traktować tego kroku jako odbioru zgodności całego HMI z obrazami.
